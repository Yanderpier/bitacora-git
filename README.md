# Bitácora de Git y GitHub

## Descripción

Repositorio de documentación técnica sobre el uso de Git y GitHub. 
Contiene conceptos, comandos y procedimientos para gestionar versiones,
repositorios locales y remotos, y sincronizar cambios.

## Contenido

- `bitacora.md`: documentación técnica de Git y GitHub.
- `.gitignore`: reglas para excluir archivos `.env` y `.log`.
